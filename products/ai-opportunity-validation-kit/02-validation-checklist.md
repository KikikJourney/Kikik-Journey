# 48-Hour Validation Checklist

## Gate 1 — Problem

- [ ] Name one buyer, not "everyone".
- [ ] Describe one painful workflow in one sentence.
- [ ] Collect at least 3 concrete evidence points.
- [ ] Separate observed facts from assumptions.
- [ ] Identify what the buyer does today.

## Gate 2 — Offer

- [ ] Define one measurable outcome.
- [ ] Define exactly what is delivered.
- [ ] Set a fixed pilot price.
- [ ] Set a delivery timebox.
- [ ] State what is explicitly excluded.

## Gate 3 — Demand

Use legitimate, targeted conversations or relevant communities.

- [ ] Contact a small number of highly relevant prospects.
- [ ] Ask about the workflow before pitching.
- [ ] Show the fixed outcome and price.
- [ ] Record objections verbatim.
- [ ] Count concrete buying signals, not likes or impressions.

## Gate 4 — Build

Build only after meaningful validation.

- [ ] Recheck third-party licenses.
- [ ] Minimize scope to the validated pain.
- [ ] Produce a working pilot before adding features.
- [ ] Define a success metric before delivery.

## Decision rule

**Payment or a strong equivalent commitment beats engagement metrics.**

If demand is weak, change the offer/problem framing before expanding the build.
