# AI Opportunity Scorecard Lite

A free, compact version of the AI Opportunity Validation Kit.

Use it to test one opportunity before spending time building.

## 15-minute test

Score the opportunity from 0–5:

| Dimension | Question |
|---|---|
| Pain | Is the problem expensive, frequent, or frustrating? |
| Buyer | Can you name the person who would pay? |
| Existing behavior | Are people already using a workaround? |
| Urgency | Does the buyer need a solution soon? |
| Deliverable | Can you describe the output in one sentence? |
| Access | Can you reach potential buyers directly? |
| Evidence | Do you have an observable signal of demand? |

### Decision rule

Do not treat the score as proof of demand.

Use the result to choose the next validation action:

1. Write one concrete offer.
2. Show it to 5 relevant prospects.
3. Ask for a paid pilot or a specific commitment.
4. Record objections and actual payment behavior.
5. Only then expand the build.
