# License & Risk Check

Before packaging third-party software into a paid product or service:

- [ ] Identify the exact repository and commit/version used.
- [ ] Read the repository LICENSE file.
- [ ] Check whether dependencies have separate licenses.
- [ ] Preserve required copyright/license notices.
- [ ] Check attribution requirements.
- [ ] Check patent terms where applicable.
- [ ] Check whether hosted/SaaS use triggers any additional obligations.
- [ ] Avoid presenting third-party code as original work.
- [ ] Keep proprietary credentials, customer data, and private code out of public workflows.
- [ ] Record the license review date and source.

This checklist is operational guidance, not legal advice.
