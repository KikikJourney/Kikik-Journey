# AI Opportunity Lab

Automated opportunity-discovery and monetization research lab.

DISCOVER -> FILTER -> SCORE -> VALIDATE -> PACKAGE -> MONETIZE

This repository is deliberately separate from Crypto-Scanner.

## What it looks for

- Recently active AI/open-source projects
- High-interest projects with weak commercial packaging
- Observable setup, deployment, integration, documentation, and workflow pain
- Niche utilities that can become audits, automations, templates, hosted tools, or implementation services

The radar does not copy proprietary code, bypass licenses, abuse APIs, or assume commercial rights without license review.

## Evidence rule

A candidate is not considered a business merely because an AI model says it is interesting. It needs observable evidence, a clear problem hypothesis, a monetizable deliverable, a low-cost validation path, and a license/commercial-use check.

## Automation

opportunity_radar.py scans public GitHub metadata every six hours through GitHub Actions and commits the latest opportunity_report.json.
